# Components

First design systems: `AmbientClock`, `OutdoorWeather`, `RoomComfort`, `LightAction`, `ClimateDial`, `TowelTimer`, `VentilationStatus`, `MasterLighting`.

After design approval, each component receives its own `spec.md` with size at 480/720, semantics, states, rendering costs and HA bindings. Start from token library, not from proprietary copies of factory code.
