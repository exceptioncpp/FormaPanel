# Критерии приёмки по этапам

## Дизайн (Phase D)

- [ ] Есть минимум 3 полноценных и *принципиально разных* стилевых концепции с главной жилой страницей 480×480.
- [ ] Для выбранного стиля есть 3 типа главной страницы и минимум 2 вторичных экрана.
- [ ] Тексты и иконки читаются на реальном устройстве, а не только в мониторе при увеличении 200%.
- [ ] Доступны мастер-ресурсы (SVG/вектор/hi-res), проверена генерация 480 и 720.
- [ ] Все состояния контролов нарисованы до интеграции с HA.

## Hardware (Phase H)

- [ ] Определена точная ревизия Guition, PSRAM/Flash, прошита тестовая программа.
- [ ] Работают изображение, touch mapping, backlight и OTA; зафиксированы ESPHome и LVGL версии.
- [ ] Проверены ориентация, offset и отсутствие артефактов.
- [ ] Измерены RAM, PSRAM и загрузка ресурсов для самого тяжёлого экрана.

## HA integration (Phase I)

- [ ] Основной экран комнаты показывает правильные реальные данные.
- [ ] Свет, климат и таймер проходят через HA и отражают подтверждённое состояние.
- [ ] В UI видны unavailable и pending без ложного состояния «исполнено».
- [ ] Автоматизация освещения в HA не нарушается действиями ручной кнопки.

## Multi-room (Phase M)

- [ ] Все 5 профилей собираются из общих модулей с конфигами комнат.
- [ ] Параметры 480×480 не зашиты в графические исходники как единственное разрешение.
- [ ] Отдельная дорожная карта для P4-720, без объявления его подтверждённой совместимости.
