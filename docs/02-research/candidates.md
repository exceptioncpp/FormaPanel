# Кандидаты дизайнерской основы: сравнение v0.1

Пока это **shortlist для обзора визуальной галереи**, а не принятые темы. «Совместим» означает существование проекта под целевой стек, но не наличие портируемого набора компонентов без переработки.

| Кандидат | Качество стилевого решения | LVGL на ESP32-S3 | Главная ценность | Ограничение |
|---|---|---|---|---|
| Заводской Guition multi-screen | выразительная художественная графика, крупные часы | да, архив LVGL 8.3.9 | реальные assets и страницы | авторские права, 8→9, внешний weather API |
| PrayerfulDrop | цельные цветовые темы | да, ESPHome LVGL 9 | готовые темы, климат/свет/погода | много лишней функциональности/зависимостей |
| alaltitov | rich wall-panel UI | да | история разработки, русский | нужно извлекать повторно используемые паттерны |
| EspControl | аккуратный карточный UI | да | навигация, настраиваемые карточки | визуально более утилитарен |
| Tessera | гибкая multi-panel визуальная система | да, иной runtime | общая конфигурация, редактор | обязательный manager, не свободное canvas-оформление |
| Neumorphic LVGL из HA Community | выразительная тактильность | отдельные примеры | объём, тени, стилистика | контраст, стоимость shadows, неоднородность исходников |
| Custom design in EEZ/SquareLine | любая композиция | зависит от export/портирования | единая собственная дизайн-система | toolchain, generated C, LVGL версии |
| OpenHASP | визуальная гибкость | проект LVGL | pages/JSONL/MQTT | отдельная платформа, не ESPHome-native |

## Предпочтительные направления для детального визуального ревью

1. **Ambient / Cinematic**: заводская Guition как визуальный референс (не слепое копирование арта), гигантские часы, фон с глубиной, мало кнопок.
2. **Warm Architectural Minimalism**: тёмный графит, теплая акцентная подсветка, точная типографика, спокойная навигация.
3. **Modern Surface / Bento**: разнокалиберные карточки, ограниченный контраст, отлично для secondary pages.
4. **Soft Tactile / Neumorphism**: ограниченно для кнопок и термостатов, не применять повсеместно без теста читаемости.

## Чего не делать

Lovelace Rounded, Mushroom, Material You — это **web UI**, они не выполняются на MCU как нативная тема. Можно изучать как референс формы и сетки, но для реализации переносить принципы, а не CSS. `RemoteWebView` с отдельным серверным Chromium — конкурентная архитектура, не «LVGL theme».

## Следующее исследование

Для каждого направления: screenshot реального устройства, композиция 480×480, размеры, тени, частота обновления, source/license, чёрно-белый контраст, asset memory, русская локализация. Решение оформить как ADR после испытаний и сравнения макетов.
