## Технические и правовые риски

- Исходный код Arduino опирается на LVGL **8.3.9**. ESPHome актуально ориентирован на **LVGL 9**: `lv_img_*`/другие API и generated code не портируются простым включением.
- В `doMain.cpp` найдены обращения к `https://www.ip.cn/api/index?ip&type=0`, `http://ip-api.com/json/` и QWeather API. **Включать этот сетевой код в FormaPanel нельзя**; погоду отдаёт HA.
- В заводском коде есть строка с ключом QWeather. Секрет/ключ не переносить и не публиковать в документации.
- Наличие исходных массивов графики в архиве **не означает** разрешение их публикации или распространения.
- Шрифты из архива требуют проверки лицензий и наличия кириллицы.
- Фоновые RGB565 ресурсы/композиции для 480×480 могут быть дорогими по Flash/PSRAM, необходимо измерить.
