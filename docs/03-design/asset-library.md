# Организация визуальной библиотеки FormaPanel

**Решение:** разделять *референсы* (история отбора визуальных решений), *мастер-исходники* (source of truth) и *скомпилированные ресурсы для устройства*.

## 1. Референсы / история выбора

```
references/
  visual/
    room-home/
      RH-01/                           # утверждённый стиль и композиция жилого экрана
        approved-composition.png        # полный макет С UI
        LA-01_OFF_ON_480_comparison.png # сравнение состояния света
        LA-01_alpha_checkerboard.png    # проверка прозрачности
    backgrounds/
      selections.md                    # перечень KEEP/REJECT и мотивы выбора
    inspiration/
      guition/                         # ссылки на заводские референсы, без копий без лицензии
```

- В `references/` — картинки **с UI**, moodboards, сравнения, исторические кандидаты, одобренные изображения, ссылки.
- Все решения, история «почему оставили/убрали» — в `docs/03-design/`, отдельные документы с ID, датой, статусом. Пример: [RH-01](room-home-reference-RH-01.md), [LA-01](light-action-reference-LA-01.md).
- Не смешивать референс-картинку с изображением, которое действительно загружается в прошивку.
- Не коммитить закрытые заводские ресурсы Guition без подтверждённого права распространения.

## 2. Исходники производственных ассетов

```
assets/
  source/
    backgrounds/
      BG-01-blue-planet/
        master.png                    # без UI, hi-res, исходная версия
        manifest.yaml                 # происхождение, авторство, лицензия, отбор, checksum
      BG-02-forest-lake/
        master.png
        manifest.yaml
    widgets/
      light-action/
        LA-01/
          LA-01-outline.svg           # единая форма для off/on
          light_on_2048.png           # RGBA, alpha
          light_off_2048.png          # RGBA, alpha
          manifest.json
    weather/
      icon-set-01/
        ...                           # единая художественная коллекция
  generated/
    480x480/
      backgrounds/
      widgets/light-action/LA-01/
        light_on.png                  # оптимизированный экспорт, сохраняет alpha
        light_off.png
      weather/
    720x720/
      backgrounds/
      widgets/light-action/LA-01/
      weather/
```

- **`source/`** — долгоживущие редактируемые master-файлы (SVG или растровые 2K/4K). Растровые фоны хранятся отдельно от UI, без часов/датчиков/кнопок.
- **`generated/`** — результаты детерминированного экспорта для конкретного профиля, с ресайзом, сглаживанием и при необходимости RGB565/LVGL-совместимым форматом. Не менять вручную.
- **`tools/`** — исходники рендереров/конвертеров: например `render_la01.py`. При этом готовые PNG и SVG относятся к `assets/`, а не к `tools/`.
- **`ui/mockups/`** — активная композиция/слои/макет UI для дисплеев, где динамический текст не запекается в фон.
- **`firmware/`** — логика и код, который использует сгенерированные ресурсы.

## 3. Нотация и стабильные идентификаторы

- Стабильные имена `BG-01`, `BG-02`, `LA-01`, `RH-01`; не `final-new3.png`.
- Для каждого ресурса фиксировать ID, `status` (`candidate/approved/rejected`), размер исходника, дату, метод получения, лицензию и хеш.
- Одобренное **визуальное направление** не значит, что бинарный asset уже проверен на аппаратуре. Различать `approved design` и `validated on device`.
- Сохранять неудачные сравнения или хотя бы причины их отклонения, не перезаписывая принятые варианты.

## 4. Специально для LA-01

Состояния `on` и `off` рендерить **из одного и того же SVG / масок геометрии**. Отдельная генерация двух картинок нейросетью даёт разные очертания — запрещена для промышленного asset-пайплайна. Отличаются лишь цвет, альфа и световой halo. Canvas, масштаб, координаты, wire gradient совпадают.

Пакет `FormaPanel-LA01-repo-ready.zip` раскладывается **непосредственно от корня репозитория**, содержит:
- hi-res RGBA 2048×2048 и SVG-модель;
- профили 480×480 (192×192 canvas) и 720×720 (288×288 canvas);
- Python-генератор `tools/render_la01.py`;
- сравнительное превью на природном фоне и шахматную альфа-подложку.

Перед публикацией в основной ветке **визуально утвердить** обе PNG на самом дисплее, проверить правильное поведение градиента провода и alpha.
