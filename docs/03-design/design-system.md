# Design system v0.1 — предложение, не утверждённая тема

## Слои

1. **Ambient canvas:** один спокойный художественный фон или мягкая цветовая глубина; избегать шумного фона под числами.
2. **Information layer:** часы → собственная температура/влажность → погода → вторичные статусы.
3. **Interactive layer:** одно крупное главное действие, затем отдельные страницы управления.
4. **Feedback layer:** состояния on/off/unavailable/pending, подтверждения/ошибки, без больших технических popup поверх часов.

## Предлагаемый визуальный язык для макетов

- Тёмный основной фон (`#0B0F16` — предварительный), тёплый янтарный accent (`#E6B46B` — предварительный), холодный вторичный (`#7CB8DD` — предварительный).
- Контрастные цифры и спокойный `secondary text`; не использовать полупрозрачный текст так, чтобы он исчезал на ярком фоне.
- Декоративная графика — маски/орбиты/градиент, но центр композиции не занят активной кнопкой.
- Точечная навигация страниц допустима, но не единственный способ узнать, где находишься; аффорданс «свайп/стрелка» нужен при первом использовании.
- Вторая страница может быть плотнее главной, но сохранять ритм, цвета и типографику.

## Компоненты (не «generic плитки»)

| Компонент | Семантика | Элементы стиля | Заметки |
|---|---|---|---|
| AmbientClock | время/дата | крупные пропорциональные или табличные цифры | динамический LVGL label, не часть PNG |
| OutdoorWeather | погода за окном | единый язык пиктограмм | наружную t° не смешивать с комнатной |
| RoomComfort | t°, RH% | пара независимых чисел, без ложного «индекса комфорта» | определить приоритет датчиков |
| LightAction | ручной свет | одна крупная affordance кнопка | визуал `pending` + подтверждение HA |
| LightScene | группы/яркость | слайдер, состояние, цветовая температура | secondary page |
| ClimateDial | климат/уставка | крупная типографика + arc/slider | объём/тени применять после замеров |
| FloorControl | тёплый пол | setpoint + фактическая t° | не предполагать наличие датчика пола без HA |
| TowelTimer | запуск в одно касание | крупный touch target + remaining | приоритет ванная |
| VentilationStatus | auto/manual, speed | лаконичные состояния | действия через HA |
| MasterLighting | global light override | повышенная информативность статуса | семантику подтвердить |

## Состояния

Обязательные: default/off, active/on, disabled, pending, unavailable, error. Цвет иконки **не** может быть единственным индикатором. Для недоступного устройства команда не должна выглядеть как активная.

## Typography

- Мастер-шрифт с поддержкой кириллицы: Inter/Roboto/другой с подтверждённой лицензией, выбрать после просмотра 480×480.
- Отдельная шкала `clock`, `hero-number`, `control-value`, `body`, `caption`, `status`.
- Глифы для каждого языка подготавливаются subset без полной загрузки Unicode в Flash.
- На 720×720 шрифты не просто умножаются на 1.5: сохранять физически комфортный размер текста на экране той же диагонали.
