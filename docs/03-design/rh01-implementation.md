# RH-01 — первая реализация главного экрана

**Текущий процесс на 01.11.2026:** [HA native preview и сборка](../06-validation/build-and-preview-runbook.md).
Описанный ниже JS-предпросмотр остаётся дополнительным приблизительным
renderer RH-01; он не заменяет уже работающий настоящий ESPHome/LVGL host.

Дата: 29.10.2026. Текущая композиционная цель — **`references/01.jpg`**, выбранный
пользователем для прошивки. Она уточняет старое описание RH-01: погода и часы
размещены **сверху**, климат и свет — снизу. Общий ambient стиль RH-01/LA-01 сохранён.

## Что реализовано

480×480, без рамок и карточек. Фон из существующего hi-res исходника
`golden-sunrise-over-alpine-lake.png`, уменьшенный Lanczos и затемнённый плавной
маской для соответствия референсу. Числа отрисовываются отдельными LVGL labels.
Nunito Bold 700 и Medium 500 находятся в репозитории вместе с OFL; сеть для
загрузки шрифтов при сборке не нужна.

| Элемент | Положение x, y | Размер / шрифт |
|---|---|---|
| Фон | 0, 0 | 480×480 RGB565 |
| Погода | 30, 27 | 64×54, alpha |
| Уличная температура | 96, 34 | Nunito Bold 30 |
| Ветер: значок / значение | 160, 43 / 197, 34 | 28×26 / Bold 30 |
| Часы | 29, 82 | Bold 72 |
| Комнатная температура | 29, 365 | Bold 64 |
| Разделитель | 138, 386 | 1×47, opacity 55% |
| Влажность / CO₂ | 155, 381 / 155, 406 | Medium 21 |
| Светильник | 374, 336 | 96×112, alpha |
| Невидимая кнопка | 366, 332 | 112×128 |

Координаты текста обозначают начало объекта LVGL; видимые цифры начинаются
ниже из-за метрик шрифта. Исходники погоды, ветра и светильника процедурные,
в `tools/render_rh01.py`. Провод лампы затухает кверху. Обе картинки лампы
используют одну геометрию: при переключении ничего не смещается.

Значения `08:00`, `+2°`, `6`, `22°`, `45%`, `680 ppm` задаются через substitutions.
Это фиксированная визуальная демонстрация. Кнопка переключает локальное
изображение лампы; реальная HA нагрузка не вызывается. Сеть/API/OTA и диагностика
панели уже присутствуют в конфигурации.

## Воспроизводимый локальный предпросмотр

Для предпросмотра нужны только лёгкие зависимости Python из `tools/requirements.txt`.
ESP-IDF, CMake, Ninja и PlatformIO на Windows не устанавливаются.

```powershell
python -m pip install -r tools/requirements.txt
python tools/render_rh01.py
python tools/preview_rh01.py
# Открыть http://127.0.0.1:8080/
```

Используется рекомендованный в исследовании
[ESPHome-LVGL-Simulator](https://github.com/MaxCRRR/ESPHome-LVGL-Simulator),
commit `170517631c1f77b107fcac254a3a5d758b826c48`; HTML проверяется по SHA-256.
В первый запуск файл скачивается с upstream, затем используется локальный cache.
Экспортируются **те же** `font`, `image`, `lvgl` и demo substitutions из прошивки.
Wi-Fi, API, OTA и secrets в браузер не передаются. Сервер доступен только
через loopback и отдаёт отдельный каталог с необходимыми ресурсами.

Штатный симулятор отображает изображения заглушками и уменьшает размер шрифта
на коэффициент 0.82. Адаптация в `preview_rh01.py` загружает настоящие PNG/TTF,
использует номинальный кегль, ascender FreeType и целочисленные advances glyphs,
сохраняет заданное положение дочернего изображения кнопки и позволяет
переключать локальный demo свет. Опциональный AI analyzer выключен.

Кнопка «Сохранить PNG» сохраняет текущий кадр в
`reports/local/rh01-preview/rh01-preview.png`. Снимки, принятые для ревью,
находятся в `ui/previews/`. Браузерный renderer не равен реальному LVGL:
антиалиасинг, RGB565, alpha, метрики и аппаратную стабильность нужно проверить
на панели. Этот preview не служит доказательством работоспособности LCD/touch.

## Проверки и следующий шаг

`python tools/validate.py` и `python -m unittest discover -s tests -v` проверяют
ресурсы и базовый pipeline. Сборка прошивки выполняется в существующем Device
Builder HA; [фактический отчёт](../06-validation/rh01-build-2026-10-29.md)
отделяет Validate/Compile от аппаратных испытаний.

После проверки ревизии и recovery — USB Factory, фото экрана, проверка GT911,
подсветки, RAM/PSRAM и OTA. Затем можно заменить mock-данные HA-сенсорами и
подключить свет с подтверждением состояния.
