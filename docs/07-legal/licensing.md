# Лицензии, сторонние ресурсы и публикация

## Policy

- **Не загружать заводской Guition ZIP**, бинарные образы, сырой исходный код демо, фоновые картинки и шрифты в публичный GitHub, пока не изучены условия правообладателя.
- В репозитории хранить метаданные: имена файлов, hash, источник, техническое описание, ссылки на официальную страницу/архив.
- Включение кода, шаблонов, SVG, шрифтов и иконок из других проектов требует проверки их конкретной лицензии и attribution.
- Pinterest/Dribbble/Behance не дают автоматически права на повторное использование изображений.
- В README нет файла LICENSE. **Лицензия FormaPanel ещё не выбрана владельцем**. Это намеренно: не нужно навязывать MIT/GPL в проекте с возможным смешиванием лицензий ESPHome/UI-kit.
- Текущие `ui/mockups/` и `assets/source/` — исходные демонстрационные материалы FormaPanel, созданные для этого проекта.

## Third-party checklist

URL, commit/tag, author, SPDX/license link, authorship of art/screenshots/fonts, distribution terms, files used, transformations, attribution text, need to include notices, version and maintenance strategy.
